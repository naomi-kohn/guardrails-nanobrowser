Agent runtime adapter

A thin SDK or proxy wraps Nanobrowser, Browser Use, Operator-like tools, and internal agents. It normalizes browser authority into inspectable events before the agent can act.

  • Hooks every proposed action before execution.
  • Splits authority into read, click, type, submit, upload, navigation, and memory write.
  • Produces signed events for audit and benchmark scoring.

Startup shape

Do not sell "a safer browser agent". Sell the policy and evidence plane every browser agent must pass through.

0-30d

Benchmark wedge

Publish poisoned-page benchmark: paraphrase injection, hidden DOM, image injection, form exfil, query-param exfil, internal-network navigation, sensitive-field typing.

30-60d

Reference adapter

Wrap Nanobrowser first. Every action becomes an event. Every event gets policy, DLP, risk score, and replay metadata.

60-90d

Design partner pilot

Target fintech, healthtech, and back-office automation teams. Sell auditability and blocked exfiltration, not abstract prompt security.
